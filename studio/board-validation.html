Timing reference and figure resolution

The comparison uses the blue stroke in Figure 8. Each image column spans 0.129 µs horizontally. One vertical pixel corresponds to 66 mV. The shaded band shows the drawn stroke thickness. The figure supplies two plotted edges and no synchronized command trigger. The SPI program and physical routing are reconstructions.

The replay uses a 48.22 kHz single-pole output filter and 0.1 µs analog steps. Band entry is measured from the 0 V crossing to the first column after which the curve centre stays within 1 V of the final nominal level for the rest of the plot.

Counter window and model

The first four records can drain at one per clock. The 4,096-record burst sets the subsequent average service time. The counter measures the transfer window inside the FPGA. Operating-system startup time is outside this window. The debugger can probe any record ordinal. The archive reports elapsed cycles for the whole burst.
