Play a waveform from memory

How can a host computer ask for a precisely timed pulse without sending every sample at the instant it is needed? Store the shape first, then give a local player a start command.

Separate loading from playing

An arbitrary waveform generator (AWG) has sample memory, a clock and a path to a voltage converter. Store a list of signed values, configure how often to read the next value, then arm the output. The trigger is the event that starts playback. A trigger can be late even when the stored list is perfect. Conversely, a correctly timed trigger can play the wrong list.

Read a published data path

QubiC stores a complex envelope and combines it with a carrier. The mobile-atom apparatus instead uses two channels of a commercial waveform generator to produce many tones for two deflectors. Several simultaneous tones in one channel can produce several spots. Increasing the number of tones changes the peaks of their sum, so the generated samples must fit the converter range. What to remember

A waveform player needs sample values, a playback clock and a trigger. The waveform duration follows from the first two, and the start time follows from the last.
