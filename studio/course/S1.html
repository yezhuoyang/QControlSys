Turn a number into a voltage

A computer can store the number 3. An electrode responds to volts. Follow one number across that boundary, then look at a measured output to see how long the change takes.

Find the outgoing wire

The block marked DAC is a digital-to-analog converter. At an update it accepts a number called a code and produces a corresponding physical level. Imagine a dimmer with eight clicks. For an ideal teaching converter with codes 0 through 7 and 0.25 volts per click, code 3 requests 0.75 V. The step size limits which voltages you can request.

Build a shape from steps

Send 0, 1, 3, 1, 0 one code per microsecond. The requested voltage forms a short hill. The rate is one million samples per second. Adding bits gives more available heights. Sending samples more frequently gives more instants at which you can change height. The analog output takes time to settle and the filter beyond the converter can round the corners.

With the teaching converter, which change doubles the number of update instants per second?

  1. One extra code bit
  2. Doubling the sample rate
Bit width changes the set of heights. Rate changes the available update times.

What to remember

A DAC turns a sequence of codes into a physical signal. Specify code range, volts per code, sample rate, and where the voltage was measured.
