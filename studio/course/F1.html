Program a circuit with a truth table

Suppose a cable carries two yes-or-no answers. Build a circuit that signals when exactly one is yes. Then change what the circuit computes by rewriting four bits.

A chip you can wire after manufacture

The right edge of QubiC’s pulse generator must deliver fresh samples on time even while the host computer is busy. Its designers implement many circuits side by side in a chip whose logic and connections can be configured after manufacture. This is a field-programmable gate array (FPGA). Its configuration describes hardware that works simultaneously. Instructions for a processor built inside it are a separate program.

Give every input an answer

One wire can carry a 0 or a 1. Two wires B and A have four combinations: 00, 01, 10, 11. Store an answer for each in that order. The four answers 0, 1, 1, 0 implement exclusive OR, written XOR. A lookup table (LUT) feeds the input bits to switches that select one answer. Three two-way selectors suffice: A selects within each pair, B selects between those two results. A six-input table in a commercial device can encode 64 answers. AMD LUT6 primitive.

Zoom in to one conducting path

In the next lab select low0.n and its partner low0.p. A transistor acts as a controlled switch. The n-type switch conducts for a high gate, the p-type for a low gate. Complementary control wires open or close the pair together. An open switch reads Z (disconnected), distinct from driving 0. The selected pair connects a stored table bit to the output wire. Each inverter also exposes its pull-up and pull-down switches.

This teaching layout uses ideal switches, initialized configuration bits and storage that holds a level while disconnected. Transistor dimensions, charge leakage, propagation delays, configuration-memory write circuits and the vendor’s physical placement are outside its model. Step through the switches.

Which table makes the output high only for B=1 and A=1?

  1. 1000 in row order 00, 01, 10, 11
  2. 0001 in row order 00, 01, 10, 11
Only the fourth row has two high inputs.

What to remember

The table bits configure a Boolean function. Input pins select the active row through a tree of switches.
