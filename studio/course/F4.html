Hand one command to a laboratory board

The FPGA must receive commands and release them in order. Follow a command from a queue to package pins and then to an instrument connector on the INO experiment controller.

Agree on when a word moves

A queue holds words in first-in, first-out order, hence FIFO. A sending circuit asserts valid when a word is available. A receiving circuit asserts ready when it can accept one. In a ready/valid interface, a transfer happens on a rising edge where both are high. If valid stays high and ready is low, the sender holds the same word. Counting valid alone would count a stalled word twice. Arm AXI-Stream specification.

Follow the INO output bus

The Trenkwalder controller’s timing logic takes a timestamped word from a queue. Seven address wires select a device, sixteen data wires carry a value, and a separate strobe tells the device when to capture it. In the archived logic simulation, data 10922 at address 21 precedes the rising strobe by 240 ns on a 20 ns clock grid. In the board pin map, data bit zero leaves package pin R14 and reaches connector J17.b25 through a buffer. The strobe goes from B19 to J17.b8. Reproduce an edge, then find a deadline

With Icarus Verilog and Python installed, run python validation/board/rtl/replay.py from the repository root. The harness checks the upstream timing-module digest, supplies its FIFO boundary inputs, and compares the simulated package outputs with the saved transitions. In the measurements panel, choose a burst and count the observed runs that miss a deadline. The physical data there are whole-burst completion counts. They cannot locate a stall on one particular edge. Compare burst deadlines.

What to remember

A transfer has a precise acceptance edge. The FIFO handshake, the converter strobe and measured burst completion each mark a different event.
