Write, test and load a hardware design

Write the clocked table as a short circuit description. Test it with artificial pins, then follow the path from named ports to a switch and a light on a real board.

Describe what is connected

Verilog is a hardware description language. A module names a circuit and its external ports. The two input bits select a table entry continuously. The clocked assignment copies that entry into Q on a rising edge. In a Verilog number the rightmost bit is bit zero. For the browser’s AND table 0001 in row order, write 4'b1000 in Verilog.

module cell_demo #(parameter [3:0] TABLE = 4'b0110)
  (input wire clk, a, b, output reg q = 0);
  wire d = TABLE[{b,a}];
  always @(posedge clk) q <= d;
endmodule

Test before fitting the chip

A testbench supplies inputs and checks outputs. Download both files to one folder. With Icarus Verilog installed, run the two commands below. The test checks capture and hold for all four input combinations. Change the table and the corresponding expected function to test another circuit. Circuit · Testbench.

iverilog -g2012 -s cell_tb -o cell.vvp cell_demo.v cell_tb.v
vvp cell.vvp

Connect the ports on a Basys 3

For a Digilent Basys 3 rev B, create a Vivado RTL project for its Artix-7 XC7A35T-1CPG236C, add the circuit as design source and the pin constraints below. With cell_demo as top module, run synthesis to map the truth table and register, then implementation to place them and route wires. Inspect clock timing against the 10 ns period. Generate the bitstream (configuration file), connect the board through USB-JTAG, and select Program Device in Hardware Manager. Switches 0 and 1 drive A and B. LED 0 lights when they differ after an edge. Mechanical switches are asynchronous and may bounce. This exercise observes their settled positions. Pin and clock constraints · Digilent pin map.

What to remember

Verilog describes the circuit, the testbench exercises it, and the constraints connect it to a particular board. Placement, routing and timing checks precede programming.
