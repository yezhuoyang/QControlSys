A general framework to simulate real quantum computers with control systems

Write a program in OpenQASM, ZAC, a QCCD Studio program or fault-tolerance system calls. It is compiled to timed hardware instructions, lowered to RV32I firmware for RISC-Q control cores, and executed batch by batch in a Lean 4 model of the controller. Then you watch that firmware drive the machine in 3D: pulses on the coax, ions shuttling through a trap, atoms carried by optical tweezers.

One controller design, RISC-Q, drives three kinds of quantum computer. Each card says how its qubits are controlled, where its hardware is designed, and which runs to open first.

Superconducting transmons

Each qubit is a transmon on a chip at millikelvin. Microwave pulses from DACs travel down coax to drive it; a readout tone into its resonator returns to an ADC and is demodulated into a bit.

Trapped-ion QCCD

Ions sit in a surface trap. Electrode voltages shuttle them between zones, lasers drive gates on ions in a gate zone, and their fluorescence under a detection beam is counted by photon detectors.

Neutral atoms

Atoms are held in optical tweezers. RF tones on acousto-optic deflectors steer moving tweezers that carry atoms between zones; Rydberg lasers entangle neighbours and a Raman laser drives one-qubit gates.

Design it as a ZAC architecture

  • A ZAC architecture file sets the zones, trap grids and AODs: validation/neutral/zac/full_architecture_2aod.json

Example runs

From a program to a pulse

Every picture in the workspace is derived from one trace. A person and a script that replay the same program see the same frames.

1 · SourceYour program

OpenQASM, a QCCD Studio program, a ZAC program, or system calls.

2 · HardwareTimed operations

Pulses, ion shuttles, AOD moves, each with a start and a duration.

3 · FirmwareRV32I machine code

One program per RISC-Q control core, issuing timed register writes.

4 · ExecutionLean 4 model

The controller runs the firmware batch by batch and emits a trace.

5 · Debugger3D, step by step

Scene, layers and inspector are rebuilt from the trace frames.
