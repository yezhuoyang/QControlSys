QuantumOS · Examples

System calls, calibrated, and the operating system under load

What each of QuantumOS's system calls actually costs on control hardware, and what happens when many of them compete for the same decoders, factories, ancillas and links. Every study runs on the cycle-exact model of RISC-Q control hardware across superconducting, neutral-atom and trapped-ion designs.

How to read these pages. A machine specification gives every system call one latency and one capacity. These examples measure what the hardware needs, how that number should be chosen, and where a single number is not enough: the variation, the queueing and the deadlocks it hides. Each page ends with the command that regenerates it.
